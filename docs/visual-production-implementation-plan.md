# 视觉资产与首帧生产实施计划

## 目标

将项目视觉生产链路固定为以下规格：

- 项目交付画幅：16:9。
- 项目交付分辨率：854x480（480P）。
- 资产设计图：Krea 2 Turbo 文生图。
- 分镜首帧：Qwen Image Edit 2511，基于已确认的资产设计图生成。
- 图片质量：medium。

模型执行尺寸和最终交付尺寸分开管理。需要满足模型像素约束时，内部可以使用与目标等比例的执行尺寸，但持久化的首帧和最终视频必须回到 854x480。

## 实施前基线

- 项目支持保存画幅和输出尺寸，但当前项目仍为 1920x1080。
- 系统已内置 Krea 2 和 Qwen Image Edit 2511 workflow。
- 当前全局图片提供方仍为 Azure Foundry，因此 Krea/Qwen 路由尚未实际启用。
- Qwen workflow 最多接受三张参考图，并由第一张参考图决定生成画布。
- 首帧生产预检与 Qwen 的三图容量、参考图顺序和版本选择尚未形成同一契约。
- 本地 ComfyUI `http://127.0.0.1:8188` 当前连接测试失败，真实端到端生成尚未验证。

## 实施阶段

### 阶段 1：尺寸与运行时路由

1. 将当前项目保存为 16:9、854x480。
2. ComfyUI 图片生成使用项目画幅对应的模型执行尺寸，不复用 GPT Image 的尺寸映射。
3. Qwen workflow 显式使用目标宽高创建首帧画布。
4. 参考图超过 workflow 容量时明确失败，禁止静默丢弃。
5. 增加尺寸、路由和参考图容量测试。

验收标准：首帧预览显示 Qwen Image Edit 2511 和 16:9 执行尺寸；超过三张参考图时在提交 workflow 前返回可理解的错误。

### 阶段 2：参考图选择契约

1. 只选择 `generation-reference` 用途的当前资源版本。
2. 只允许审核通过或明确激活的资产设计图进入首帧生产。
3. 参考图按“场景、主要人物、次要人物、关键道具”的稳定规则排序。
4. 预检显示实际会发送给模型的图片和顺序。
5. 三张以上输入通过 16:9 参考图组合板合并，避免遗漏群像角色或关键道具。

验收标准：预检结果和实际 Qwen 输入完全一致，相同输入可重复得到相同参考图顺序。

### 阶段 3：审核、预览与可复现性

1. 增加资产设计图审核和锁定状态，未确认资产不得用于批量首帧。
2. 将已有 `production/preview` 接入分镜页面，生成前展示模型、尺寸、完整提示词和参考图。
3. 持久化 ComfyUI `prompt_id`、seed、workflow hash 和参考图资产 ID 顺序。
4. 批量任务支持按失败项重试，并保留每项错误。

验收标准：用户可以在 UI 中确认生产参数，并能依据产物元数据重放单镜头任务。

### 阶段 4：真实端到端验证

1. 启动并通过 ComfyUI 能力检测。
2. 生成一张 Krea 资产设计图并完成审核。
3. 使用该资产图生成一张 Qwen 首帧。
4. 校验 PNG 魔数、854x480 尺寸、合理文件大小和数据库 provenance。
5. 通过后再开放整集批量生产。

验收标准：真实文件、数据库记录和 ComfyUI 历史三方一致；不以 mock 测试代替真实生成证明。

## 风险与回退

- 854 不是常见模型步长的整数倍，ComfyUI 内部执行尺寸应归一到 16:9 且满足模型步长，最终输出再裁放到 854x480。
- 修改项目设置会使依赖当前设置的视觉资产标记为过期；切换前应保留版本，不覆盖历史产物。
- workflow 节点变更必须同步能力检测，否则 UI 就绪状态可能是假阳性。
- 在单镜头真实验证通过前，不启动批量生成，避免浪费 GPU 时间。
