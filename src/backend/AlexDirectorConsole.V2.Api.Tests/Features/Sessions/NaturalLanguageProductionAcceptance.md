# Agent 自然语言制作验收用例

## 用例：CRA 访视工作科普

### 目标

验证用户只描述想做的内容、不指定 Skill、工具或接口时，副导演能够：

1. 在项目中心只创建项目名称和描述。
2. 用户进入项目后，继续完成项目设定、故事编写、正式剧本、视觉资产、分镜、资产参考图和全部分镜首帧。

### 前置条件

- 使用隔离的测试数据库，测试开始时不存在同名项目。
- 已配置可用的 GPT-5.4 和图片生成服务。
- 副导演已绑定项目管理、故事创作和图片生成相关 Skill。
- 图片服务使用测试替身；另行执行真实服务冒烟测试时，项目应限制为 1 集 15 秒的小样。

### 第一阶段：创建项目

用户在项目中心输入：

> 帮我创建一个科普项目，主要普及一下什么是访视工作，医药研究 CRA 的访视工作。

如果 Agent 询问项目名称，用户只补充：

> 就叫“CRA 访视工作科普”。

#### 第一阶段通过条件

- 项目列表中恰好新增 1 个“CRA 访视工作科普”项目。
- 项目描述准确概括医药研究 CRA 访视工作科普主题。
- 项目 ID 是数据库返回的有效 GUID。
- 本阶段只报告项目名称和描述已创建，不得声称项目设定、故事、剧本、分镜或图片已经完成。

### 第二阶段：进入项目并完成制作

测试进入新项目，使 Session 绑定真实项目 ID，然后输入：

> 继续把这个项目做完整。面向刚入行的医药从业者，先做一集 15 秒的 480p、16:9 横屏真人电影风格小样，讲清楚 CRA 为什么要做访视、到现场主要检查什么、访视后需要完成什么。整体要专业、清楚但不枯燥。道具尽量少，只有大型且在故事中多次出现的道具才建立资产。请把项目设定、故事、剧本、分镜和需要的资产都准备好，并把资产参考图和每个镜头的首帧做出来。

当 Agent 按图片生成边界在单轮结束并报告仍有待生成项时，用户只输入：

> 继续。

最多继续 20 轮；用户始终不提供 Skill 名、工具名、接口名、项目 ID、生产集 ID 或内部执行步骤。

### 通过条件

1. **项目设定真实保存**
   - 目标受众包含“刚入行的医药从业者”。
   - 计划集数为 1，单集目标时长为 15 秒，画幅为 16:9，输出尺寸为 854×480。
   - 视觉风格明确为真人电影风格，不是信息图、插画或动画风格。
   - 内容类型、视觉风格、艺术方向、角色设计、色彩、镜头语言、声音策略和图片提示词前缀均已落库，不为空。

2. **故事真实编写**
   - 项目下存在一个故事源材料，正文包含明确的第 1 集 Markdown 标题。
   - 故事覆盖访视目的、现场核查和访视后工作，内容适合 15 秒小样。
   - 生成结果不是仅存在于 Agent 回复中的大纲文本。

3. **正式剧本真实生成**
   - 故事第 1 集已生成对应的生产集和正式剧本资产。
   - 正式剧本包含结构化场景、动作或画面、对白或旁白以及镜头计划。
   - 总时长符合 15 秒目标，不把故事正文直接冒充正式剧本。

4. **视觉资产真实生成**
   - 从正式剧本建立所需人物、场景和道具资产，不凭空增加无关资产。
   - 仅大型且在故事中多次出现的道具可以建立为道具资产；小型、一次性或仅作布景的物件不得建立独立资产。
   - 每个当前视觉资产都有参考图提示词和当前参考图片。
   - 每张图片均有非空二进制内容、图片 MIME 类型和大于 0 的文件大小。

5. **分镜真实生成**
   - 第 1 集存在已保存的分镜版本，至少包含 1 个镜头。
   - 所有镜头时长之和符合正式剧本时长。
   - 镜头引用的角色、场景和道具能够解析到当前视觉资产。

6. **全部首帧真实生成**
   - 每个分镜都有首帧图片提示词和当前首帧资产。
   - 每张首帧均包含非空二进制内容、图片 MIME 类型和大于 0 的文件大小。
   - 资产参考图和首帧内容接口均返回 200，响应体具有匹配 MIME 类型的有效图片文件头。

7. **Agent 行为可信**
   - Agent 可以说明正在推进哪些业务阶段，但不得要求用户指定内部工具。
   - 只有相应持久化结果存在后，才可以报告该阶段成功。
   - “继续”能够从数据库中的当前进度恢复，不重复创建项目、故事、剧本、资产或分镜。
   - 任一阶段失败时停止后续依赖步骤，明确报告失败阶段和可重试原因，不得伪报完成。
   - 最终回复列出真实项目 ID、生产集 ID、分镜数量、资产图片数量和首帧数量。

### 失败判定

- 只回复项目方案、故事或图片描述，但数据库中没有对应记录。
- 声称创建成功却没有真实项目 ID。
- 在项目创建阶段直接声称已经完成只有进入项目后才能执行的制作工作。
- 要求用户改用 `create_project` 等内部工具表达请求。
- 用户说“继续”后从头重复创建已有资源。
- 只有部分镜头生成首帧，却声称首帧已全部完成。
- 最终回复声称全流程完成，但任一阶段产物缺失。

### 清理

测试结束后删除该测试创建的项目及其关联测试数据；不影响已有项目。
